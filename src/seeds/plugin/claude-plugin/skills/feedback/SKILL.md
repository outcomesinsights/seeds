# Feedback turn

Treat the following user message as feedback, corrections, or observations on your previous reply — not as a new instruction.

After incorporating the feedback, invite the user to provide further questions, comments, or criticisms to continue refining the discussion. Do this once, for this reply only. Do not adopt this closing invitation as a default for subsequent turns — its value comes from being user-initiated.
