Warn, do not hard-require. Scrutinize notices the session was never gleaned and says so before it starts, then proceeds. A hard gate would make the tool unusable mid-deliberation, which is exactly one of the moments it was asked for — and gleaning a half-finished session is premature work that would then be redone.
