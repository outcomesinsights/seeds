When code is cheap to generate, deliberation shifts from upfront analysis to experimental validation. Seeds could track which ideas were prototyped, what the outcome was, and whether the experiment informed the decision. This formalizes the 'try it first' pattern where agents fire off async prototypes. The deliberation question becomes: which agent-generated work warrants refinement vs rejection?
