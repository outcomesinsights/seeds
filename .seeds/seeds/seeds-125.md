The user identified a terminology overload problem: 'gathering seeds' is ambiguous when seeds is both the tool name and the thing being extracted. Agriculture offers precise vocabulary:

- **Gleaning**: Gathering leftover grain/seeds after a harvest — fits the idea of extracting valuable seeds from already-produced documents (transcripts, articles, conversations)
- **Threshing**: Separating seeds from the chaff — fits the process of identifying what's relevant vs noise in a source document
- **Winnowing**: Separating wanted seeds from unwanted — fits the filtering/scoping step where you decide what's relevant to THIS project

The full metaphor maps well:
1. Source document = the harvested crop
2. Gleaning = extracting candidate seeds from the document
3. Threshing = separating actionable ideas from noise
4. Winnowing = scoping to the current project's concerns

'Glean' as a command name: `seeds glean <source>` — more precise than 'harvest' or 'sweep', implies picking through existing material rather than growing something new.
